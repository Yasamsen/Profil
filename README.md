# Yasam Portfolio

A responsive personal portfolio made with plain HTML, CSS, and vanilla JavaScript (no React, TSX, or build step).

## Run locally
Open `index.html` in a browser. For a local server, from this folder run:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.

## Customize before publishing
- Replace `Yasam` and the biography in `index.html`.
- Change `sera@example.com` to your real email address.
- Update GitHub and Instagram links to your profiles.
- Replace the sample project cards and links with real projects.
- The portrait uses a remote Unsplash image; replace its URL if you want a different portrait.
- The CV button is intentionally represented by the contact CTA; add your own CV file and link if needed.
